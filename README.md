# Тамға — башкирская языковая школа

Платформа, на которой школьники, учителя, носители языка и все желающие каждый день переводят фрагменты башкирских текстов, проверяют автоперевод и вместе собирают базу подтверждённых переводов для разных языковых пар.

## Возможности

- **Ежедневное задание.** Пять фрагментов в день: башкирский текст с координатами источника и автоперевод. Перевод можно подтвердить или исправить. Иногда в автоперевод подмешан заведомо неверный вариант — за его исправление начисляется бонус.
- **Серия («огонёк»).** Серию держат пять **верных** заданий в день: если поверить подставной ошибке, задание не засчитывается. По кнопке «Продолжить переводить» фрагменты идут дальше без ограничения, порциями по десять.
- **Аудиоисточники.** Для аудиокниги или радиопередачи учитель загружает файл и расшифровку строками вида `00:07 текст`: фрагменты получают отрезки времени и кнопку «послушать в записи» — звучит именно тот кусок, из которого фрагмент нарезан.
- **Автоматическая разметка аудио.** «Разложить мой текст по паузам» — если расшифровка есть, программа находит в записи звучащие куски, подгоняет их число под число предложений и расставляет время сама; модель не нужна, работает без интернета. «Расшифровать запись» (необязательный модуль, `install_asr.bat`) — модель сама находит границы предложений и пишет текст. Разметка идёт в фоне: страница показывает ход работы, а при неудаче — понятную причину, а не общую ошибку.
- **Озвучка.** Каждый фрагмент и перевод можно прослушать: башкирский — моделью MMS-TTS на сервере (если установлена) или голосом браузера, перевод — голосом браузера на языке пары.
- **Согласование по долям.** Каждый ответ — голос за вариант. Варианты, которые значат одно и то же, считаются вместе: не важны регистр, «ё» и пунктуация; не важен порядок слов; слова из `app/synonyms.txt` (мама = мать, книга = книжка…) сводятся к одному; варианты, отличающиеся одним похожим словом («книгу» — «книжку»), объединяются, а непохожим («вчера» — «сегодня») — нет, поэтому подставная ошибка никогда не сливается с верным переводом. Правило настраивается в `app/envload.py` (значения по умолчанию можно переопределить локально в `.env`):
  - пока ответов меньше `CONSENSUS_MIN_VOTERS` (3), идёт сбор;
  - варианты, набравшие меньше `CONSENSUS_NOISE` (20 %) голосов, не засчитываются;
  - среди засчитанных вариант с долей от `CONSENSUS_SHARE` (60 %) подтверждается;
  - если сильных вариантов несколько и ни один не набрал порог — случай уходит экспертам.
- **Качество корпуса.** Обрывки словарных статей и строки со сбитым выравниванием отсеиваются при импорте (`quality.py`), уже загруженные прячет `clean_fragments.py`, а на остальное ученики жалуются кнопкой «Задание странное»: после трёх жалоб (или сразу от персонала) фрагмент уходит из выдачи.
- **Геймификация.** XP, уровни, шесть достижений, рейтинги: все / школа / класс / между школами; за день, неделю, месяц, год; по баллам, словарному запасу, исправлениям и числу ошибок. За зажжённый огонёк (выполненную дневную норму) начисляется бонус `XP_FLAME` (15 XP). Опыт — ещё и валюта: если пропущен ровно один день, погасшую серию можно **восстановить за `STREAK_REPAIR_XP` (100 XP)** на странице «Серия» — как в Duolingo; рейтинги при этом не искажаются, потому что считаются по заработанным очкам из ответов, а не по текущему балансу. Уровень (1 уровень = 500 XP) показывается рядом с ником в комментариях (опытность в вопросах перевода) и рядом с именами в отчёте по классу (насколько усердно ученик занимался), в том числе в CSV.
- **Роли.** Ученик, учитель (отчёт по классу, нарезка текстов), модератор, эксперт (решение спорных случаев), администратор.
- **«Интересное».** Факты о языке и культуре (факт дня), вопросы с подвохом с объяснениями, «Собери предложение» из слов с лишними словами-ловушками (задания строятся из базы фрагментов) и контрольная из 10 заданий с оценкой. XP за обучение — не больше 50 в день.
- **Интерфейс на русском и башкирском**, маскот — куница в башкирском камзуле: рисунок переведён в вектор и разложен на слои (хвост, тело, голова), анимация живёт внутри SVG.
- **Языковая пара** (ba-ru, ba-kk, ba-en, ba-alt, ba-ar, ba-sah, ba-zh) хранится в профиле: выбор переносится на другое устройство и в Telegram-бот.
- **Страницы из шапки**: «Серия» (календарь 28 дней, лучшая серия), «Опыт» (уровень и таблица начислений), «Профиль» (школа, класс, достижения).
- **Регистрация** на сайте (код подтверждения на почту) или в Telegram-боте. Школу и класс ученик **не выбирает из огромного списка**: учитель указывает свою школу и класс в настройках, получает **код класса** и раздаёт его ученикам — по коду ученик сразу попадает в свой класс (и в рейтинги школы). Так учителя курируют состав своих классов.
- **Telegram-бот**: регистрация, задание дня с кнопками «Верно / Исправить / Послушать», прогресс, недельный рейтинг, выбор языковой пары, вход на сайт по одноразовой ссылке. Аккаунт сайта привязывается к боту из настроек сайта. Состояние диалога хранится в базе (таблица `tg_users`), команды `/start`, `/cancel`, `/task`, `/stats`, `/top`, `/settings`, `/lang`, `/help`.
- **Напоминания куницы.** Пока дневная норма не выполнена, бот напоминает о ней; текст зависит от того, сколько часов осталось до нового дня (шесть «ступеней» по 4 часа, чем ближе полночь — тем настойчивее: от «Позанимаемся башкирским?» до «Я начну кусаться»), а язык — от языка пользователя в боте (русский или башкирский). Из каждой ступени — не больше одного напоминания в день, фраза выбирается случайно из трёх. До часа `REMIND_FROM` (по умолчанию 8:00) бот молчит, чтобы не будить ночью; напоминания можно выключить в настройках бота.
- **Отчёт учителю** по классу на сайте и выгрузкой в CSV (открывается в Excel) — для электронного журнала и LMS.

## Стек

Python 3.12 · FastAPI · aiogram 3 · SQLAlchemy 2 · PostgreSQL (локально — SQLite) · ванильный JS без сборки · Argon2id для паролей · Docker + Caddy (HTTPS).

## Структура

```
app/
  main.py      приложение, заголовки безопасности, обработка ошибок
  models.py    схема данных
  api.py       вход, аккаунт, роли, администрирование
  extra.py     регистрация, школы, ежедневные задания, согласование, база, рейтинги, API для внешних систем
  links.py     привязка Telegram, вход из бота, коды классов
  bot.py       Telegram-бот (aiogram 3)
  quality.py   отбраковка плохих пар корпуса
  clean_fragments.py  прячет уже загруженные плохие пары
  asr.py       автоматическая разметка аудио: расшифровка и разбивка по паузам (необязательно)
  synonyms.txt словарь синонимов для согласования (можно дополнять)
  learn.py     вкладка «Интересное»: факты, вопросы, сборка предложений, контрольная
  tts.py       серверная озвучка (необязательно)
  seed.py      стартовые данные
  static/      интерфейс (index.html, app.js, style.css, img/)
import_hf.py       импорт параллельных фраз из датасета Фонда сохранения и развития башкирского языка
import_schools.py  импорт списка школ Башкортостана
tests/             автотесты (pytest)
```

## Схема собранных переводов

| Поле | Описание |
|---|---|
| `fragment_id` | идентификатор фрагмента |
| `text_ba` | фрагмент на башкирском |
| `lang_pair` | языковая пара, например `ba-ru` |
| `translation` | подтверждённый или исправленный перевод |
| `source` | координаты источника: `doc`, `chapter`, `position`, `audio_from`, `audio_to` |
| `confirmed` | число пользователей, выбравших этот вариант |
| `status` | `confirmed` или `expert_review` |

## API

Интерактивная документация — `/docs` (Swagger).

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/daily?pair=ba-ru[&extra=true]` | задание на сегодня (или дополнительные фрагменты) |
| POST | `/api/answer` | ответ: подтвердить или исправить перевод |
| POST | `/api/fragments/{id}/report` | жалоба на задание |
| POST | `/api/fragments/{id}/audio` · GET `/api/audio/{id}` | запись голоса носителя и её воспроизведение |
| GET | `/api/base?pair=&status=` | подтверждённые, идущие и спорные переводы |
| GET | `/api/rating?scope=&period=&metric=` | рейтинги |
| GET | `/api/tts/{fragment_id}` | озвучка фрагмента (WAV) |
| GET | `/api/learn/facts` · `/quiz` · `/build` · `/test` | факты, вопросы, сборка предложений, контрольная |
| GET | `/api/teacher/report[?format=csv]` | отчёт учителю по классу |
| POST | `/api/teacher/invite` | код класса для регистрации учеников |
| POST | `/api/tg/link-code` · `/api/tg/login` | привязка Telegram и вход на сайт из бота |
| GET | `/api/expert/queue` · POST `/api/expert/{id}/decide` | спорные случаи |
| GET | `/api/v1/export?pair=&format=json\|csv` | выгрузка базы (ключ `X-API-Key` или роль персонала) |
| GET | `/api/v1/fragments` | фрагменты с координатами источника |
| PATCH | `/api/me/pair` | языковая пара пользователя |
| POST | `/api/admin/slice` · `/api/admin/fragments` | загрузка материалов (`mode`: `sentence`, `paragraph`, `audio`) |
| POST | `/api/admin/audio?doc=` · GET `/api/media/{fragment_id}` | аудиоисточник и его выдача для прослушивания отрезка |
| POST | `/api/admin/transcribe` | запустить разметку: `mode` = `asr` или `pauses`; возвращает номер задания |
| GET | `/api/admin/transcribe/{job}` · `/api/admin/asr-check` | ход работы и проверка распознавания |

## Локальный запуск

**Самый простой путь — `demo.bat`** (инструкция: [какзапустить.txt](какзапустить.txt)). Он последовательно устанавливает пакеты и озвучку, загружает датасеты и список школ, а затем запускает сайт и Telegram-бота. При первом запуске можно указать данные для подключения Telegram, внешнего API и почты; ненужные подключения можно пропустить. Демо-аккаунты всех ролей: `student@demo.ru`, `teacher@demo.ru`, `moderator@demo.ru`, `expert@demo.ru`, `admin@demo.ru`, пароль `demo123`. Остальные действия — в `menu.bat`.

Только сайт без бота и туннеля: дважды щёлкнуть `start.bat` — он создаст окружение, установит зависимости и откроет http://127.0.0.1:8000.

Вручную:

```
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cd app
uvicorn main:app --reload
```

Для разработки в `.env` удобно поставить `DEMO_SEED=1` (демо-аккаунты `student@demo.ru`, `teacher@demo.ru`, `expert@demo.ru`, `admin@demo.ru`, пароль `demo123`) и `DEV_SHOW_CODE=1` (код подтверждения показывается на экране, если почта не настроена).

Импорт данных (из папки `app`):

```
python ../import_hf.py --lang kk      # alt, ar, kk, sah, zh
python ../import_schools.py
```

Telegram-бот: создать бота у [@BotFather](https://t.me/BotFather), вписать в `.env` `TELEGRAM_TOKEN`, `BOT_USERNAME` и `PUBLIC_URL`, затем из папки `app` запустить `python bot.py` (Windows — `start_bot.bat`). Сайт и бот — два отдельных процесса с общей базой.

Серверная озвучка: `pip install -r requirements-tts.txt` (Windows — `install_tts.bat`).

Автоматическая расшифровка аудио — два варианта, оба необязательные:

| | многоязычная | башкирская |
|---|---|---|
| установка | `install_asr.bat` (`requirements-asr.txt`) | `install_asr_ba.bat` (`requirements-tts.txt`) |
| размер | ~0.5 ГБ | ~1.5 ГБ |
| `ASR_MODEL` | `small` | `AigizK/bashkir-whisper-small` |
| башкирский текст | латиницей, в задания не попадёт | кириллицей, ошибок около 15 % |
| скорость на обычном ноутбуке | быстрее | медленнее |

Имя с косой чертой программа считает моделью с Hugging Face и запускает через `transformers`, короткое имя — через `faster-whisper`. Есть и крупнее: [AigizK/whisper-medium-ba](https://huggingface.co/AigizK/whisper-medium-ba). Режим «разложить по паузам» не использует модель вообще и работает без интернета.

Строки, записанные не башкирской кириллицей, нарезка пропускает, а кнопка «Спрятать латиницу из заданий» убирает уже загруженные.

Тесты: `pip install -r requirements-dev.txt`, затем `python -m pytest -q tests`.

## Публичный запуск

Нужен сервер с Docker и домен, направленный на его IP.

1. Скопировать проект на сервер, рядом создать `.env` по образцу `.env.example`: `DOMAIN`, `POSTGRES_PASSWORD`, почта, `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `API_KEY`, `DEMO_SEED=0`, `DEV_SHOW_CODE=0`.
2. `docker compose up -d --build` — поднимутся PostgreSQL, сайт, Telegram-бот и Caddy, который сам получит HTTPS-сертификат.
3. Загрузить данные:
   ```
   docker compose exec app python ../import_hf.py --lang kk
   docker compose exec app python ../import_schools.py
   ```
4. Войти под `ADMIN_EMAIL` и выдать роли учителям и экспертам во вкладке «Управление».

Обновление: `git pull && docker compose up -d --build`. Резервная копия базы: `docker compose exec db pg_dump -U tamga tamga > backup.sql`.

Приложение можно развернуть и на PaaS-хостинге с Docker и PostgreSQL: достаточно передать переменные из `.env.example` и `DATABASE_URL` базы; порт берётся из переменной `PORT`. Лимиты запросов хранятся в памяти процесса, поэтому запускайте один процесс приложения.

## Безопасность

Пароли — Argon2id; в базе хранится только хеш токена сессии, срок жизни 7 дней; блокировка завершает все сессии; лимиты запросов на вход, регистрацию, ответы и публичный API; роль при регистрации всегда «ученик»; проверка ответа на сервере (клиент не знает, где подставная ошибка); CSP и заголовки безопасности; журнал действий администраторов и экспертов.
