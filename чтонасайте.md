# Тамға — краткий гид для проверяющего

**Тамға** — платформа «башкирского Duolingo» по задаче 3 хакатона: веб-сайт + Telegram-бот + накапливаемая база парных переводов с геймификацией. Название — от родового знака «тамга»: каждый перевод — знак, оставленный сообществом.

## Как запустить и войти

`demo.bat` в корне проекта делает всё сам (подробно — [какзапустить.txt](какзапустить.txt)): по шагам, с процентами, устанавливает пакеты и озвучку, загружает датасеты и школы и поднимает сайт с публичной ссылкой `https://….trycloudflare.com` + Telegram-бота. Все настройки уже в `.env` — вводить ничего не нужно.

Демо-аккаунты (пароль у всех — `demo123`):

| Роль | Вход | Что смотреть |
|---|---|---|
| Ученик | `student@demo.ru` | задания, серия, опыт, рейтинги, «Интересное» |
| Учитель | `teacher@demo.ru` | вкладка «Класс»: отчёт, CSV, код класса, загрузка материалов |
| Модератор | `moderator@demo.ru` | вкладка «Экспертам»: очереди на проверку |
| Эксперт | `expert@demo.ru` | решение спорных переводов и записей голоса |
| Администратор | `admin@demo.ru` | вкладка «Управление»: роли, блокировки, школы |

## Что где на сайте

- **Главная** — приветствие куницы-маскота, дневная цель 5/5, уровень, достижения, последние переводы.
- **Переводить** — ежедневное задание: башкирский фрагмент с координатами источника (произведение, глава, № предложения; у аудио — отрезок записи с кнопкой «послушать»), автоперевод. Действия: «Перевод верный» / «Исправить». Иногда в автоперевод подмешана заведомая ошибка (30 %): поверил — задание не зачтено, поймал и исправил — бонус +5 XP. Кнопка «Задание странное» — жалоба, после 3 жалоб фрагмент уходит из выдачи. После 5 заданий — «Продолжить переводить» без ограничений, порциями по 10.
- **База** — накопленные переводы по вкладкам: подтверждённые / в процессе / спорные / мои, с долями голосов по вариантам, комментариями и выгрузкой JSON/CSV (для персонала). Правило согласования написано прямо на странице.
- **Интересное** — факты о языке и культуре (факт дня), вопросы с подвохом, «Собери предложение» со словами-ловушками, контрольная из 10 заданий. XP за «Интересное» — не больше 50 в день.
- **Рейтинг** — все / моя школа / мой класс / между школами; день / неделя / месяц / год / всё время; баллы / словарный запас / исправления / меньше ошибок.
- **Класс** (учитель) — отчёт по ученикам + выгрузка CSV для электронного журнала (LMS-совместимость), **код класса** для регистрации учеников, загрузка материалов: нарезка текста по предложениям/абзацам, загрузка аудио с расшифровкой по отметкам времени, автоматическая разметка (по паузам / распознаванием речи).
- **Экспертам** (модератор/эксперт) — спорные переводы с долями голосов, очередь записей голоса носителей.
- **Управление** (админ) — пользователи, роли, блокировки, добавление школ, материалы.
- **Шапка**: Серия (календарь 28 дней), Опыт (уровень, откуда XP), Профиль, Настройки (язык интерфейса русский/башкирский, языковая пара, школа — для учителя, привязка Telegram).

## Ключевые механики

- **Огонёк (серия)** — держат 5 *верных* заданий в день; поверил подставной ошибке — не считается. За зажжённый огонёк — **бонус +15 XP** (ровно раз в день).
- **XP — это ещё и валюта.** Пропустил ровно один день — погасшую серию можно **восстановить за 100 XP** (страница «Серия», как в Duolingo). Рейтинги не искажаются: они считаются по заработанным очкам из ответов, а не по текущему балансу XP.
- **Уровень виден людям**: рядом с ником в комментариях к переводам (опытность комментатора в вопросах) и рядом с именами в отчёте по классу у учителя, включая CSV (насколько усердно ученик занимался). 1 уровень = 500 XP.
- **Школа и класс — только по коду.** Ученик не выбирает школу из списка: учитель указывает свою школу/класс в настройках, получает код (вкладка «Класс») и раздаёт ученикам. Код вводится при регистрации на сайте, в боте (`t.me/<бот>?start=КОД`) или позже в настройках. Так рейтинг школ честный, а учителя курируют составы классов.
- **Согласование по долям**: ответ = голос за вариант; синонимы, порядок слов, «ё» и пунктуация объединяются; при ≥3 ответах вариант с долей ≥60 % (после отсева шума <20 %) подтверждается, при двух сильных вариантах случай уходит экспертам. XP за перевод приходят только когда вариант подтверждён сообществом — накрутка бессмысленна.
- **Проверка на сервере**: клиент не знает, где подставная ошибка (таблица `shown`).
- **Озвучка**: башкирский — модель MMS-TTS на сервере или голос браузера; живой голос носителя проходит голосование учеников → эксперта и только потом звучит в заданиях.

## Telegram-бот

`/start` — регистрация (имя → код класса) или продолжение; кнопки «Задание дня / Прогресс / Рейтинг / Настройки»; «Верно / Исправить / Послушать» в заданиях; выбор языковой пары (общая с сайтом); вход на сайт по одноразовой ссылке; `/lang` — русский ⇄ башкирский.

**Напоминания куницы**: пока дневная норма не выполнена, бот напоминает о ней. День разбит на 6 «ступеней» по 4 часа — чем меньше часов до нового дня, тем настойчивее фраза (от «Позанимаемся башкирским?» утром до «Я начну кусаться» вечером); из каждой ступени не больше одного напоминания, фраза случайна из трёх, язык — русский или башкирский по настройке пользователя. До 8:00 бот молчит (`REMIND_FROM`).

## Данные и API (интеграция — главное требование ТЗ)

- Схема записи перевода — как в ТЗ: `fragment_id, text_ba, lang_pair, translation, source (doc/chapter/position/audio_from/audio_to), confirmed, status`.
- Интерактивная документация API — `/docs` (Swagger). Выгрузка: `GET /api/v1/export?pair=ba-ru&format=json|csv` (ключ в заголовке `X-API-Key`, значение — в `.env`), фрагменты с координатами — `GET /api/v1/fragments`. Отчёт учителю: `GET /api/teacher/report?format=csv`.
- Данные: датасет «Башкирские трёхъязычные разговорники» (БГПУ им. М. Акмуллы / Фонд сохранения и развития башкирского языка, CC BY 4.0) — пары ba-ru, ba-kk, ba-alt, ba-ar, ba-sah, ba-zh; полный список школ Башкортостана.

## Соответствие ТЗ (п. 9 «Критерии оценки»)

| Критерий | Где |
|---|---|
| Полный цикл: материалы → фрагменты → задание → согласование → фиксация | «Класс»/«Управление» (нарезка) → «Переводить» → «База» → «Экспертам» |
| Геймификация и рейтинги | XP, уровни, бейджи, огонёк (+15 XP), 4 вида рейтингов × 5 периодов |
| Документированность данных и API | README (схема, таблица API), Swagger `/docs` |
| UX: минимум действий, мотивация | 2 клика на задание, куница, конфетти, звуки, 2 языка интерфейса |
| Устойчивость | лимиты запросов, Argon2id, роли, аудит, автотесты `tests/` |

Безопасность: пароли Argon2id, в базе только хеш токена сессии, лимиты на вход/регистрацию/ответы/API, роль при регистрации всегда «ученик», CSP-заголовки, журнал действий персонала.

Стек: Python 3.12 · FastAPI · aiogram 3 · SQLAlchemy 2 · SQLite/PostgreSQL · ванильный JS · Docker + Caddy для публичного развёртывания (`docker-compose.yml`).
