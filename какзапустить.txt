ТАМҒА — КАК ЗАПУСТИТЬ САЙТ И TELEGRAM-БОТА
==========================================

Сайт и бот запускаются на обычном компьютере с Windows. Пока компьютер включён и окно
программы открыто — сайт открывается с любого телефона по ссылке, бот отвечает в Telegram.
Всё, что ученики делают в боте, сразу видно на сайте, и наоборот.

При первом запуске программа запросит данные для подключения Telegram, внешнего API и почты. Если какая-либо функция не нужна, соответствующее поле можно пропустить. При вводе секретных данных символы НЕ отображаются — это нормально. Настройки сохраняются автоматически.


ШАГ 1. УСТАНОВИТЬ PYTHON (один раз, 5 минут)
--------------------------------------------
1. Откройте https://www.python.org/downloads/release/python-3128/
   Внизу страницы нажмите «Windows installer (64-bit)», скачайте и запустите.
2. ВАЖНО: в первом окне установщика поставьте галочку
   «Add python.exe to PATH» (внизу окна), затем нажмите «Install Now».
3. Дождитесь надписи «Setup was successful» и закройте окно.


ШАГ 2. СКАЧАТЬ ПРОГРАММУ (один раз)
-----------------------------------
1. Откройте страницу проекта.
2. Зелёная кнопка «Code» -> «Download ZIP».
3. Найдите скачанный архив tamga-main.zip в папке «Загрузки», нажмите на него правой кнопкой
   -> «Извлечь всё» -> «Извлечь». Появится папка tamga-main.


ШАГ 3. ЗАПУСТИТЬ
----------------
1. Откройте папку tamga-main и дважды щёлкните файл demo.bat
   (если Windows покажет синее окно «Windows защитила компьютер» —
   нажмите «Подробнее» -> «Выполнить в любом случае»).
2. Откроется чёрное окно. Программа сама, по шагам, скачает и установит всё нужное.
   У каждого шага написано «ШАГ 1/6, 2/6…» и видны проценты загрузки — по ним понятно,
   сколько ждать. ПЕРВЫЙ запуск идёт 15–30 минут (скачивается около 1,5 ГБ:
   библиотеки, башкирская озвучка, датасеты фраз и список школ). Окно не закрывайте.
   Сайт запустится только когда всё будет готово — докачивать после запуска ничего не придётся.
3. Когда в окне появится рамка из знаков ===== со строкой
        САЙТ: https://какие-то-слова.trycloudflare.com
   — сайт работает. Браузер откроется сам.
   Эту ссылку можно отправить ученикам: она открывается с любого телефона.
4. Бот: найдите его в Telegram и напишите /start.

В СЛЕДУЮЩИЙ РАЗ запуск занимает 1–2 минуты: все шаги с пометкой «уже установлено — пропускаю».


КАЖДЫЙ СЛЕДУЮЩИЙ РАЗ
--------------------
Дважды щёлкнуть demo.bat -> дождаться ссылки -> работать.
Ссылка меняется при каждом запуске — отправляйте ученикам новую.
Остановить: закрыть чёрное окно. Пока окно закрыто, сайт и бот не работают.


КАК ВОЙТИ
---------
Готовые демо-аккаунты (пароль у всех: demo123):
    admin@demo.ru      — администратор (выдаёт роли во вкладке «Управление»)
    teacher@demo.ru    — учитель (отчёт по классу, код класса, загрузка материалов)
    expert@demo.ru     — эксперт (решает спорные переводы)
    moderator@demo.ru  — модератор
    student@demo.ru    — ученик
Ученики и учителя также регистрируются сами: своей почтой или через Telegram-бота.
Если почта не подключена, письма не отправляются, а код подтверждения показывается на экране.

Школу и класс ученик НЕ выбирает из списка: учитель получает в своём профиле
«код класса» и раздаёт его ученикам — по коду ученик сразу попадает в свой класс.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
* «Python not found» — Python установлен без галочки «Add python.exe to PATH».
  Запустите установщик Python ещё раз -> «Modify» или удалите и установите заново с галочкой.

* Браузер пишет «Не удаётся получить доступ к сайту» — ссылка ещё «не дошла» до интернета.
  Подождите минуту. Затем: Пуск -> введите cmd -> Enter -> в чёрном окне наберите
        ipconfig /flushdns
  и нажмите Enter, потом обновите страницу (F5). Или откройте ссылку с телефона.
  На этом же компьютере сайт всегда открывается по адресу http://127.0.0.1:8000

* В окне ошибки «TelegramConflictError ... only one bot instance» — бот запущен
  на другом компьютере тоже. Бот может работать только в одном месте: закройте demo.bat
  на другом компьютере.

* Бот не отвечает — проверьте, что в файле .env заполнена строка TELEGRAM_TOKEN
  (это делает разработчик перед передачей проекта).

* Сайт пишет «Почта не настроена, код: 123456» — письма не отправляются, но регистрация
  работает: введите показанный код.
